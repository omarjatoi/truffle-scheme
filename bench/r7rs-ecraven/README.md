# Vendored benchmark set: ecraven's r7rs-benchmarks

Read-only (AGENTS.md), apart from this README. The benchmark set most Scheme
comparisons use, with published results for many implementations at
https://ecraven.github.io/r7rs-benchmarks/ (plan.md M5-01).

- **Upstream:** https://github.com/ecraven/r7rs-benchmarks, at the commit named
  in `benchmarks.tsv`. `SHA256SUMS` lists every vendored file's digest.
- **Authors:** Larceny's R7RS benchmarks (collected and written by Richard
  Gabriel, Marc Feeley, Will Clinger and others), adapted by the repository's
  owner, GitHub user ecraven, and contributors to run on many implementations.
- **License:** the repository has no license file. Its `README.org` says the
  benchmarks are "taken with kind permission from the Larceny project", and
  they are Larceny's `test/Benchmarking/R7RS` programs. Larceny's notice
  (`../r7rs-larceny/COPYRIGHT`) says of them: "All of those programs are
  distributed by permission of the copyright holders; for specific copyright
  notices, please consult the files themselves." Files with their own notices
  keep them (`maze.scm`, `parsing.scm`, `equal.scm`, ...).

  So we vendor only what that permission covers: the programs, the shared
  harness (`common.scm`, `common-postlude.scm`) and the inputs, unchanged.
  We don't redistribute ecraven's own additions, which carry no license: the
  `bench` script, the README and the per-implementation preludes and
  postludes (`src/<Impl>-prelude.scm`, ...). M5-02's comparative report runs
  other implementations with their preludes: it fetches them at run time from
  the pinned commit in `benchmarks.tsv` rather than committing them here.
  Nothing in the implementation includes or links these files; they are
  benchmark inputs.

## What is here

Copied unchanged by `mx r7rs-vendor-benchmarks ecraven`:

- `src/<program>.scm`: the 57 programs of upstream's `bench` script's
  `ALL_BENCHMARKS`.
- `src/common.scm`: the shared harness, `run-r7rs-benchmark` (time `count`
  runs of a thunk, then check the last result); `src/common-postlude.scm`:
  `(run-benchmark)`. Upstream's `bench` builds a program as
  `cat <impl>-prelude.scm <program>.scm common.scm <impl>-postlude.scm
  common-postlude.scm` and runs it with `inputs/<program>.input` on standard
  input.
- `inputs/`: each program's `.input` (`count`, the arguments, the expected
  result) and the data files programs read.

Generated by the same command, from the checkout's `bench` script:
`benchmarks.tsv` (the programs, in `bench`'s order, with its group) and
`SHA256SUMS`.

How `mx benchmark` runs them, and the programs that fail: `../README.md`.

## Re-vendoring

```
git clone https://github.com/ecraven/r7rs-benchmarks /tmp/r7rs-benchmarks
mx r7rs-vendor-benchmarks ecraven /tmp/r7rs-benchmarks --commit $(git -C /tmp/r7rs-benchmarks rev-parse HEAD)
```
