# Vendored benchmark set: Larceny's R7RS benchmarks

Read-only (AGENTS.md), apart from this README. The R7RS benchmarks of the
Larceny project, which ecraven's set (`../r7rs-ecraven/`) was taken from
(plan.md M5-01). This set has the same programs, with its own inputs (often
larger counts), plus 16 programs for the R7RS Red Edition libraries.

- **Upstream:** Larceny, https://github.com/larcenists/larceny,
  `test/Benchmarking/R7RS/`, at the commit named in `benchmarks.tsv`.
  `SHA256SUMS` lists every vendored file's digest.
- **Authors:** Richard Gabriel collected some of the programs, Marc Feeley and
  Will Clinger collected or wrote others, Abdulaziz Ghuloum converted them to
  R6RS libraries, and Clinger rewrote them as R6RS and then R7RS programs
  (upstream's `README`).
- **License:** `COPYRIGHT` is Larceny's notice, copied from the root of the
  repository. For the `test` directory it says: "All of those programs are
  distributed by permission of the copyright holders; for specific copyright
  notices, please consult the files themselves." Files with their own notices
  keep them (`maze.scm`, `parsing.scm`, `equal.scm`, ...). The files are
  redistributed unchanged, as benchmark inputs: nothing in the implementation
  includes or links them. (Larceny's R7RS *test* suite in
  `tests/r7rs-larceny/` is LGPL because it derives from Racket's tests; these
  benchmarks don't.)

## What is here

Copied unchanged by `mx r7rs-vendor-benchmarks larceny`:

- `bench`: upstream's driver script, which defines the set
  (`ALL_BENCHMARKS`: 73 programs, 16 of them `RED_EDITION`) and how a program
  is built: `cat <program>.scm common.scm`, run with `inputs/<program>.input`
  on standard input.
- `src/`: the programs and the shared harness `common.scm`
  (`run-r7rs-benchmark`, then a call to the program's `main`).
- `inputs/`: each program's `.input` and the data files programs read.
- `README`: upstream's README. `COPYRIGHT`: Larceny's notice.

Generated by the same command: `benchmarks.tsv` (the programs, in `bench`'s
order, with its group) and `SHA256SUMS`.

How `mx benchmark` runs them, and the programs that fail: `../README.md`.

## Re-vendoring

```
git clone --filter=blob:none --sparse https://github.com/larcenists/larceny /tmp/larceny
git -C /tmp/larceny sparse-checkout set test/Benchmarking/R7RS
mx r7rs-vendor-benchmarks larceny /tmp/larceny --commit $(git -C /tmp/larceny rev-parse HEAD)
```
